# Работа с проектом

Это домашнее задание по C++17. Основная функция считает простую скользящую
среднюю. Здесь же находятся тесты, пример и замеры скорости.

## Где что лежит

- `include/quant/` - заголовок с описанием функции для Doxygen.
- `src/` - реализация и пример запуска.
- `tests/` - тесты на doctest.
- `benchmarks/` - бенчмарк на nanobench.
- `third_party/` - сторонние библиотеки и лицензии.
- `.github/workflows/` - сборка и публикация документации на GitHub.

## Команды

Выполнять из корня проекта:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure
./build/quant_demo
./build/quant_benchmark
cmake --build build --target docs
```

В Windows с MinGW нужен параметр `-G Ninja` при настройке CMake, а у программ
будет расширение `.exe`. В Visual Studio при сборке добавляется
`--config Release`, при запуске CTest - `-C Release`.
Программы в этом случае лежат в `build/Release/`.

## Правила

- Перед завершением работы собрать проект и запустить тесты.
- Использовать C++17, отступы в 4 пробела и snake_case для функций и переменных.
- Если меняется поведение функции, проверить это в тестах, включая крайние случаи.
- Сохранить проверку входных данных и линейную сложность расчёта.
- Не править файлы сторонних библиотек и готовую HTML-документацию.
- Не менять CI/CD без запроса пользователя.
- Не добавлять в коммиты сборку, пароли, токены и локальные пути.
