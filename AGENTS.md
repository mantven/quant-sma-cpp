# Инструкции для агента

Назначение: учебный проект C++17 для количественного анализа. Библиотека
вычисляет простую скользящую среднюю (SMA) за линейное время.

## Структура

- `include/quant/`: публичный API с комментариями Doxygen.
- `src/`: реализация и консольный пример.
- `tests/`: unit-тесты doctest.
- `benchmarks/`: измерения nanobench.
- `third_party/`: закреплённые версии зависимостей и их лицензии.
- `.github/workflows/`: сборка, проверки, бенчмарк и публикация документации.

## Команды из корня репозитория

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure
./build/quant_demo
./build/quant_benchmark
cmake --build build --target docs
```

В Windows с MinGW используйте `-G Ninja`; бинарники имеют суффикс `.exe`.
Для Visual Studio добавляйте `--config Release` при сборке и `-C Release`
при вызове CTest, бинарники лежат в `build/Release/`.

## Правила

- Перед завершением изменений соберите проект и запустите тесты.
- C++17, отступы 4 пробела, имена функций и переменных в snake_case.
- Изменения поведения сопровождайте проверками граничных случаев.
- Сохраняйте документированный API, проверку входных данных и сложность O(N).
- Не редактируйте vendored-зависимости и сгенерированную документацию.
- Не меняйте CI/CD без прямого запроса пользователя.
- Не коммитьте build, токены, пароли и машинозависимые пути.
